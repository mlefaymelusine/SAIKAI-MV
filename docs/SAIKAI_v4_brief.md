# SAIKAI MV 第四版 brief（草案 0.4）

> 这份文件把我们在几个线程里聊出来的要求，按 world.execute(me) 那份提示词的格式整理成「规则 + 逐段方向」。
> 你继续用聊天的方式提意见就好，我负责把每次的结论写回这里。标 **【待定】** 的地方需要你拍板。
> 来源：「良秀与阿赖耶 Saikai MV 制作」线程里你对 v1–v3 的反馈、「Saikai 原创 MV」、本线程的 14 条 v3 意见，以及两份角色锚点。

## 零、这一版要解决什么

v3 的叙事方向（阿赖耶独白做主线、蜘蛛网一次、结尾 I.L.Y.T.）保留，只解决三个总问题：

1. **人物**：v3 的剪影和设定对不上，有几张身体扭曲。改成以物件和颜色为主，人物只留三处，剪影重新设计并逐张核对。
2. **线**：红线太多、太粗、自己游动，像触手。改成细、实、只被拉动。
3. **风格统一**：写实书包、手绘双手、星空、游戏 CG、白描父辈混在一起。全片收成一种语言，向 Saikai 原创版的干净留白靠拢。

## 二、总规则

### 1. 一种画面语言
- 风格题词：良秀的「无人能及的部分，在于削减。在于缩略。」——能删的就删，能用一个点代替一个词就用点。
- **剪纸版画**：和纸底（米白或墨黑两种纸），平涂色块，最多一层错开的阴影版。不用渐变、不用写实质感、不用 3D 渲染感。
- **Blender 场景**（v4 工程的一部分，用户支持）：只用平涂自发光材质 + Freestyle 剪纸边线，颜色只取第二节色值，看起来仍是纸。现有三个：方形时间保险箱（V1 打开 / W4 倒放关上）、屋顶夜景（C2 两人背影、W2 城市平移、O2 烧毁版）、里恩的绘本（R1 翻开到空白末页、O2 合上）。蜘蛛网隧道沿用 v1。
- 线条只有两种：剪纸的边，和「线」本身。不用白描人物，不用照游戏 CG 描线。
- 留白是默认值。每个镜头要能回答「这是故事的哪一刻」；答不出来就删掉，不要加东西去填。

### 2. 颜色就是人（颜色只在事件发生时变）
| 颜色 | 代表 | 规则 |
| --- | --- | --- |
| 黑白 + 红点缀 | 良秀 | 按官方配色：白衬衫白马甲、黑裤、黑外套披肩；红色只在外套内衬、刀穗、红线这些小地方（已定，不再全身涂红） |
| 红 | 红线 | 面积要克制 |
| 藏青 | 阿赖耶 | 全片都用藏青代表她（已定）。刀鞘上三行字亮起时用更亮的蓝紫（她的台词色约 #5c53e7），这个亮色只在那一刻出现 |
| 白 | 刀鞘「阿赖耶识」、纸 | |
| 黑 | 蜘蛛巢、父辈 | |
| 灰 | 被斩掉的记忆 | 一样东西被斩，就褪成灰轮廓，之后不再上色 |
| 紫（熊） | 中指父辈的熊 | 唯一的例外色，只在熊身上 |

### 3. 人物
- 只保留三处：开头母女牵手走（远景、小）、屋顶看星星（背影）、结尾重逢。
- 这个项目只由我们两个完成，不另外约稿。这三处剪影由我们自己设计、生成，再按锚点逐张核对（发型、比例、刀的位置），过不了就不用，退回物件。
- 其他所有出现人的地方，都换成物件或手。手也只用简单的剪纸形状，不画写实的手。
- 五位父辈换成五件物品：拇指＝金色的券、食指（里恩）＝没有结局的绘本、中指＝紫色的熊、环指＝骨刀、小指（地慧星）＝面纱。
- 关键一斩不做人物转换，改成刀入鞘。
- 剪影生成时不画刀；刀和刀鞘由代码单独画、再合成，保证每个镜头形状一致。
- 人物用 gpt-image 生成平涂剪影，再按颜色分版、统一换成全片色值。
- 不用游戏 CG、游戏立绘、游戏贴图。例外：v3 的 sword_h / sheathed_h 两张刀与鞘的线稿（若出自官方剪影素材库，用户确认可留），只在 G4 入鞘那一镜用。其余镜头的刀和鞘由代码画。

### 4. 线
- 同一画面最多一两根，细，不发光，不缠满全身。
- 线自己不动，只被拉紧、放松、剪断。
- 「一根变很多根」只用龙须糖的分法：1→2→4→16。

### 5. 文字
- **字幕**：只有中英两行，在固定位置、固定字号，整段不变；有人声时只放歌词；一句歌词从开唱显示到下一句开唱，淡入淡出约 1 秒。字幕下面的画面要留出干净的底，不压在复杂图形上。
- **点缀文字**：阿赖耶的独白做成从上方垂下的挂幅（v3 的做法保留），只放在前奏、间奏、桥段、尾奏。选句以「线团 → 龙须糖 → 谢谢你来找我 → 名字 Ryō-shū → 想成为妈妈的妈妈 → I.L.Y.T.」为主线，不要句句都放。
- **竖排中文**：只给挂幅用，不用来放歌词。【待定】
- **关键词大字**：只有两处，S 那两句和结尾的 I.L.Y.T.（英文缩写，不用汉字）。
- 熊的对白不用。

### 6. 节奏
- 一句歌词大致一个镜头，在换气处切；转场以慢叠化和推拉为主。镜头数 20–30 个。
- 主动作对准人声（唱到那个词的时候），不只对鼓点。
- 所有不在歌词起点上的时间，集中写在一个 `cues` 文件里，每行一个，注明是实测还是估计；你听过以后只改这一个文件。

### 7. 物件的标准
- 第一帧就是一个干净、一眼认得出的轮廓；大块面，不要细线小图标。
- 不吓人：没有细丝一样的边、没有触手、没有扭曲的身体。
- 每个物件单独渲染一帧，不看字能说出是什么才算过关。
- 具体形状：保险箱是方形的箱子加转盘，不是圆形金库门（游戏原文：「特别的时间保险箱」，旋钮「设置在五年以内」，门板上写着这四个字）；里恩的绘本讲的是原文里蜘蛛绕网三千轮的故事，夹着书签，最后一页空白；章鱼香肠是一截短香肠，切出几条短腿，故意有点歪；杯子是圆柱形的日式茶杯（汤吞）；抚子花是五片平涂花瓣，边上只剪几个缺口。

### 8. 删除清单（v3 → v4）
深海触手一样的红线、爬梯子、游戏 CG 和描 CG 的线稿、所有生成的人物剪影、扭曲的跪姿剪影、站在地球上的阿赖耶、熊的对白、汉字结尾。

## 五、工作方式

- 先做「样张」：每个物件和三处人物占位各出一帧 1920×1080，不带字幕，给你看过再剪。
- 每段做完都渲染出来自查，每个镜头看三帧：切点后、主事件、结束前。
- 自查清单（每个镜头）：这是哪一刻 / 为什么在这里结束 / 颜色符合第二节吗 / 风格统一吗 / 字幕读得清吗 / 主动作对上人声吗 / 引入或回收了哪个母题。
- 维护一份「没有照 brief 做的地方及原因」，交付时一起给你。
- 没改的段落用数值比对，不重看。
