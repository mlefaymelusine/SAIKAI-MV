## 四、做法备忘

- **序列帧**：`<Seq name frames keys=[[秒, 帧]...]>` 按歌曲时间分段线性取帧，文件名为 `NNNN.jpg`，帧号从 1 开始。缺帧会让渲染失败，所以只在可见时渲染 Seq。
- **Blender 风格**：平涂 emission 材质（调色板 hex 转线性）加 Freestyle 描边，放进 `nolines` 集合的物体不描边。
  - 设 `SAIKAI_OVERWRITE=0` 可以续渲，跳过已有的帧。
  - 用 `BLENDER=…` 指定 Blender 路径。
  - **Blender 文字对象遇到笔画重叠的字（如「年」）会填错**。中文一律用 PIL 生成贴图。
- **抠图**：在黑底和白底各渲染一次，`a = 1-(w-b)/255`，`rgb = b/a`（`walk_rgba.py`）。
- **字体**：Google Fonts css2 加 `text=` 取子集。改了画面文字就要重跑 `python v4/tools/fonts.py`，否则新字会显示成后备字体。
- **字幕可读性**：暗场线稿多的镜头加 `<SubBand/>`。亮场上大物件要让出底部约 140px。
- **设备传输**：
  - 读设备文件用 device_stage_files，每次最多 50 个，落到 `/mnt/user-data/uploads/mv_saikai/...`。
  - 写回设备用 device_commit_files，每次最多 50 个文件，单个 ≤30 MB，合计 ≤100 MB，源文件必须在 `/mnt/project-files/` 下。
  - 设备上已有的大文件（wav、webtunnel）用 device_bash 在设备内复制，不上传。
- **调色板**：ink #0e0b10，paper #ece4d4，white #faf8f2，red #c0182c / #d62838，navy #26345c，navyDeep #18213d，violet #5c53e7，grey #8d8780，gold #c9a446。
